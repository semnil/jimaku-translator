# UI の決定

> For the English version, see [ui.md](ui.md).

GUI ([src/ui/index.html](../../src/ui/index.html)) について閉じた判断と、却下した案を持つ。

## toast は上部の中央に出す

- **決定** (2026-05-04): 保存の結果 (成功・エラー) を知らせる toast は、ウィンドウの上部の中央に固定する (`.toast`: `position: fixed; top: 20px; left: 50%`)。ほかのどれよりも手前 (`z-index: 10000`) に、影と、上から降りるアニメーションを付けて出す。
- **理由**: ウィンドウの下端の保存ボタンの横では、toast が見落とされやすい。
- **却下した案**: 下、または右下の隅 (前の位置)。保存ボタンの直下の inline のメッセージ (通知がまたボタンの隣になる)。
